# SLE-MDD-ML-Signature

Exploratory machine learning signature for major depressive disorder (MDD) based on systemic lupus erythematosus (SLE)-shared immune signatures. This repository contains the complete source code for data preprocessing, differential expression analysis, functional enrichment, ssGSEA immune-related signature score analysis, systematic evaluation of 107 machine-learning pipelines, model selection, post-hoc statistical analysis, and figure generation for the associated manuscript.

## Data

All data are publicly available from the NCBI Gene Expression Omnibus (GEO):

| Accession | Disease | Role in this study |
|---|---|---|
| GSE138458 | SLE | Discovery cohort (shared-DEG identification) |
| GSE98793 | MDD | Training cohort (2 batches, batch-corrected) |
| GSE251778 | MDD | Post-selection exploratory evaluation cohort (female and male subgroups) |
| GSE52790 | MDD | Post-selection exploratory evaluation cohort |

Intermediate expression matrices derived from these datasets can be regenerated by running the scripts below in the stated order; the sample_manifest.csv file lists every sample, its accession, group, cohort assignment, and sex.

## Execution order

1. `pipeline_code/00_GEO_data_download.R` — download of the GEO datasets
2. `pipeline_code/00_ID_conversion.R` — probe annotation and gene-ID conversion
3. `01_preprocess.R` — normalization and training-cohort preparation
4. `02_batch_correction.R` — ComBat batch correction of GSE98793
5. `03_DEG_analysis.R` — limma differential expression analysis and shared-DEG identification
6. `04_enrichment.R` — GO / KEGG / DOSE enrichment analysis
7. `05_ssGSEA.R` — ssGSEA immune-related signature score analysis
8. `pipeline_code/07_ml_107_pipelines.R` — training and evaluation of all 107 machine-learning algorithm combinations
9. `06_model_evaluation.R` — evaluation of the selected glmBoost + Stepglm[both] model (ROC, calibration, odds ratios, nomogram)
10. `pipeline_code/08_feature_selection.R` — feature-selection frequency across pipelines
11. `pipeline_code/09_ROC_curves.R` — ROC curve plotting

The three non-training cohorts (GSE251778_F, GSE251778_M, GSE52790) were used as post-selection exploratory evaluation cohorts in model selection (mean AUC); they do not constitute independent external validation.

## Random seeds

Random-number generators are seeded at the top of each analysis script (`set.seed`), so that running the scripts in the stated order reproduces all reported results.

## Repository layout

- Root: analysis scripts 01–06 in execution order
- `pipeline_code/`: data download, ID conversion, and the 107-pipeline machine-learning code
- `old_versions/`: superseded working scripts retained for reference only
- `1_preprocessingData/`, `DGIdb/`, `Figure2_revised/`, `Figure3/`, `Figure4/`, `Figure5/`: intermediate data and figure outputs
